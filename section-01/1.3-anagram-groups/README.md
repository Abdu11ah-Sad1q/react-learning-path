# Task 1.3: Anagram Groups & Palindrome Check

## Overview

- **Anagram Groups**: Groups a list of words where all anagrams share the same bucket, returning the largest groups first. Case-insensitive and handles single words / empty arrays gracefully.
- **Bonus Palindrome**: Validates whether a sentence is a palindrome using an in-place two-pointer strategy while ignoring spaces, punctuation, and casing.

## Usage

Run the script using Node.js:
\`\`\`bash
node section-01/1.3-anagram-groups/index.js
\`\`\`
