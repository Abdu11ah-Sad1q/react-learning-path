# Task 1.1: Expense Report

## What I Built

A set of plain JavaScript utility functions to process and aggregate household expenses:

- `getTotalByCategory`: Groups and sums expenses by category using .
- `getCategoriesBySpend`: Sorts category names in descending order based on accumulated spend.
- `getTotalByMonth`: Groups expenses by `YYYY-MM` extracted from the date string.
- `getLargestExpense`: Identifies the item with the highest amount.

## How to Run

From the root directory:

```bash
node section-01/1.1-expense-report/index.js
```
