# Task 2.1: Course Catalog Cards

A responsive course catalog interface built with React and Tailwind CSS that dynamically renders course cards from structured data, featuring conditional badges, price formatting, and dynamic course insertion.

## 🚀 How to Start the Project (Getting Started)

Follow these steps to run the project locally on your machine:

### 1. Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (version 18 or newer recommended).

### 2. Open Terminal

Navigate into the directory of this specific task:

```bash
cd section-02/2.1-course-catalog-cards
npm install
npm run dev
```
